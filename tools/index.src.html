A growth playbook from your website

Paste your website. It finds your three closest competitors, keeps the growth moves at least two of them repeat, and drops the ones your team or budget can't run.

The approach. Facts before advice: Google search data, Meta ads, LinkedIn and X posts, and what ChatGPT says when a buyer asks for a tool. Every move shows its proof, and the page ends with the bill. A run stops at $0.50.

Test run: Youform against Jotform, Typeform and Fillout. All three were named in every ChatGPT answer checked, Youform in none. $0.24 in data.

An ad agent that pauses what loses

It watches your Meta ad account every hour, pauses the ads losing money, moves budget to the winners and drafts new versions of your best ad.

The approach. You write the rules down in one file. For the first week it only lists what it would pause. When you agree with its calls, it starts acting, under a daily spend cap it cannot raise.

Test run: a 14-day export of six made-up ads, every rule firing once, 10 tests passing. It only reports. It never touches an account.

500 pages from one spreadsheet

One page template and one row of data per page: a page for every city, product or comparison your buyers search for.

The approach. A row only becomes a page if it has real demand and enough real data, and thin rows are skipped with the reason. I read a sample before anything goes live, then watch which pages Google actually indexes and fix or drop the rest.

Test run: 30 real keyword rows became 21 pages. 5 mirror searches merged, 4 thin rows skipped with the reason.

A hundred video ads from one photo

How I think about the problem

Most marketing work is a loop someone repeats by hand. I sort every step of the loop into one of five bricks first, so the agent only gets the work that needs judgment. That keeps it cheap and stops it making things up.

ScheduleWhen it runs, on its own.

  1. Find the loop

    Where does someone repeat the same steps every week? That is where an agent pays for itself. A one-off task is not worth building.

  2. Write the rules down

    When to pause an ad, which pages are thin, what a good hook sounds like. Rules live in plain files you can read and edit. The agent follows them and does not invent its own.

  3. Run it in report-only mode

    It lists what it would do and changes nothing. You read its calls for a week. It acts only once you agree with them, and every action is logged with the numbers behind it.

  4. Hand it over

    You own the code and the accounts. You get the run log, the stop rules and one page on how to fix it when it breaks.

Six rules I build by

Written down so you can hold me to them.

  1. Automate the loop, not the task.
  2. If you can hardcode it, hardcode it.
  3. Every agent gets a job description and a log.
  4. Autonomy is earned. Every agent starts with a human approving its work.
  5. Test it on the ugliest data you have.
  6. You sign the work.

Build for the boring Tuesday. Demos are easy. The test is whether it still runs in week nine, unattended, when you have forgotten it exists.
